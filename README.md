# ⚡ EcoCircuit: Misión Red Eléctrica Inteligente (Smart Grid Guardian)
### Proyecto Educativo STEAM — Grado 11° | Institución Educativa Angela María Torres Suárez

Bienvenido al repositorio oficial del proyecto **EcoCircuit**, un videojuego educativo interactivo desarrollado en JavaScript nativo (HTML5 Canvas) diseñado para enseñar los principios físicos, matemáticos y ambientales de la transición hacia energías renovables y la gestión de redes eléctricas inteligentes (*Smart Grids*).

---

## 📂 Estructura del Repositorio

- **`docs/`**: Contiene la documentación pedagógica y técnica completa.
  - [`DOCUMENTACION_COMPLETA_STEAM.md`](docs/DOCUMENTACION_COMPLETA_STEAM.md): Cuaderno maestro del proyecto con las 26 misiones, matrices STEAM, rúbricas de evaluación (100%), bitácoras de IA y registros de errores. Este archivo se utilizará para compilar el informe final en formato Word (`.docx`).
- **`src/`**: Código fuente del videojuego.
  - `index.html`: Estructura semántica de vistas (Menú, Tutorial, Lienzo de Simulación, Modal de Retos, Resultados).
  - `style.css`: Estilos visuales con estética Solarpunk / Clean Energy.
  - `js/`: Arquitectura modular en JavaScript ES6+ (motor de simulación, controladores de UI, sistema de retos didácticos).
  - `assets/`: Recursos gráficos (iconos de paneles, turbinas, baterías, subestaciones) y efectos sonoros.

---

## 🚀 Cómo Ejecutar el Videojuego

1. Abre el archivo `src/index.html` en cualquier navegador moderno (Google Chrome, Edge, Firefox).
2. O bien, si utilizas Visual Studio Code, haz clic derecho sobre `src/index.html` y selecciona **"Open with Live Server"**.
3. No requiere instalación de Node.js ni librerías externas pesadas. ¡100% portable para salas de cómputo escolares!
