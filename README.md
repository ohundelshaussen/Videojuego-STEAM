# 🇨🇴 Tesoros de Colombia: Guardianes del Patrimonio
### Proyecto Educativo STEAM — Grado 11° | Institución Educativa Angela María Torres Suárez

Bienvenido al repositorio oficial del videojuego educativo interactivo **Tesoros de Colombia: Guardianes del Patrimonio**, desarrollado en **JavaScript con Phaser 3**. 

El juego tiene como objetivo fortalecer la identidad cultural y el conocimiento del patrimonio histórico, precolombino, independentista y regional de Colombia a través de una experiencia interactiva y visual de clasificación (*Drag & Drop*) en las salas del Museo Nacional.

---

## 📂 Estructura del Repositorio

- **`docs/`**: Documentación pedagógica y cuaderno de trabajo STEAM.
  - [`DOCUMENTACION_COMPLETA_STEAM.md`](docs/DOCUMENTACION_COMPLETA_STEAM.md): Cuaderno maestro con las 26 misiones completas, matrices STEAM, rúbricas institucionales (100%), bitácoras de IA y registros de pruebas. Archivo base para la exportación final a Word (`.docx`).
- **`src/`**: Código fuente modular del videojuego.
  - `index.html`: Estructura HTML5 y modales del museo.
  - `style.css`: Estilos visuales de museo, acentos tricolores y efecto Glassmorphism.
  - `lib/phaser.min.js`: Motor 2D oficial Phaser 3 (compatible 100% offline).
  - `js/`: Escenas desacopladas (`BootScene.js`, `MenuScene.js`, `GameScene.js`, `ResultScene.js`, `config.js`, `main.js`).
  - `assets/`: Ilustraciones vectoriales de artefactos patrimoniales y efectos de sonido.

---

## 🚀 Cómo Ejecutar el Videojuego

1. Abre el archivo `src/index.html` en tu navegador favorito (Chrome, Edge o Firefox).
2. O bien, abre la carpeta en Visual Studio Code, haz clic derecho sobre `src/index.html` y selecciona **"Open with Live Server"**.
3. ¡No requiere Node.js, npm ni configuraciones complejas! Listo para usarse en las salas de cómputo del colegio.
